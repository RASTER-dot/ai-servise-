# AI Test Service

Это микросервис на Python (FastAPI), который принимает текстовый запрос, отправляет его в нейросеть (OpenAI/совместимый API) и возвращает сгенерированный ответ.

## Стек технологий
* Python 3.11
* FastAPI (веб-фреймворк)
* Pydantic (валидация данных)
* Docker & Docker Compose
* httpx (асинхронные запросы к AI)

## Как запустить проект локально

1. Убедитесь, что у вас установлен и запущен Docker Desktop.
2. Склонируйте репозиторий или скачайте папку с проектом.
3. В корневой папке создайте файл .env (можно скопировать .env.example и переименовать).
4. Откройте .env и впишите ваш реальный ключ от API в переменную AI_API_KEY.
5. В терминале выполните команду:
   ```bash
   docker compose up --build
